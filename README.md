## About

This is Uzbek Xinux community (nix users mostly) member's maintained version of nixpkgs registry data collection with automated ci jobs.

Datas stored inside `data/` and organized according to branch names which includes whatever inside `versions` file:

- nixos-25.05
- nixos-25.11
- nixos-unstable
- nixpkgs-unstable
